# pieisspy.github.io

This is a portfolio to view my projects, powered by [`sv`](https://github.com/sveltejs/cli).

## Developing

To view the dev build of the website, use these commands in the CLI:

```sh
npm run dev

# or start the server and open the app in a new browser tab
npm run dev -- --open
```

## Building

To build the app, use this command in the CLI:

```sh
npm run build
```

You can preview the production build with `npm run preview`.
